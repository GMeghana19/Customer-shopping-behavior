# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer purchasing behavior, spending patterns, product preferences, and seasonal trends using Python. The objective is to derive actionable business insights that support data-driven decision-making.

## Dataset

- Total Records: 3,900
- Total Attributes: 18
- Dataset: shopping_trends_updated.csv

The dataset includes customer demographics, purchase amounts, product categories, subscription status, seasonal preferences, and review ratings.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Methodology

### 1. Data Exploration
- Understanding dataset structure and data types
- Identifying numerical and categorical variables
- Generating descriptive statistics

### 2. Data Quality and Validation
- Checking missing values and duplicate records
- Validating age, purchase amounts, and review ratings
- Validating categorical values

### 3. Exploratory Data Analysis
- Customer demographic analysis
- Product and category performance
- Seasonal purchasing trends
- Customer spending patterns
- Subscription and discount analysis
- Location-wise purchasing behavior

### 4. Statistical Analysis
- Purchase amount percentile analysis
- Correlation between customer age and spending
- Analysis of spending distribution

### 5. Data Visualization
- Bar charts
- Histograms
- Box plots
- Heatmaps
- Scatter plots

## Key Findings

- Clothing was the most frequently purchased category, followed by Accessories.
- Customer age showed a negligible linear correlation with purchase amount.
- Seasonal and category-wise analysis revealed purchasing patterns useful for business planning.

## Business Recommendations

- Optimize inventory based on product demand and seasonal trends.
- Develop targeted marketing strategies based on customer preferences.
- Evaluate subscription benefits and promotional strategies to improve customer engagement.
